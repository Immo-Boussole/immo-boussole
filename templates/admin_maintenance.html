Configuration de l'API Google (Client ID / Secret)
Guide Rapide d'obtention des clés :
  1. Allez sur la Google Cloud Console.
  2. Activez les API Google Calendar API et Google People API.
  3. Configurez l'écran de consentement OAuth (ajoutez votre adresse pilote en utilisateur de test).
  4. Créez des identifiants de type ID de client OAuth (Application Web).
  5. Définissez l'URI de redirection suivant dans les paramètres Google :
    https://your-domain.com/api/auth/google/callback
  6. Récupérez le fichier JSON d'identifiants ou copiez le Client ID / Client Secret ci-dessous.
Pour plus de détails, consultez le Guide Google OAuth sur le Wiki.
